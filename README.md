## 🧠 Engineering Mindset

I don't just want to write code — I want to understand how the **whole system** works.

```mermaid
flowchart LR
    A([Idea]) --> B[Design]
    B --> C[Software]
    B --> D[Hardware]
    C --> E[Test]
    D --> E
    E --> F[Improve]
    F --> G([Share])
    F -.-> E
```

The interesting part is usually **connecting everything together**.
